Everything under `benchmark/` is regenerated by:

```bash
python scripts/aggregate_results.py
```

which reads the per-cell JSON files under `$KBC_OUTPUT_ROOT/results` and
publishes here. Re-running it after more cells finish updates the tables and
figures in place.
